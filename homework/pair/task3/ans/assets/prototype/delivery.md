## 初稿基础与 v2 修订

本轮实际编辑中，免费版拒绝了多动作与 `CONDITIONAL` 反应的写入。导航、搜索修订脚本已生成相应布局，但这些脚本中的部分交互未成功应用；后续使用免费版修复脚本重接单动作跳转与静态状态页。不能据此宣称变量驱动交互、自由输入、动态筛选数据或真实状态持久化已经可用。

免费版搜索采用有限状态：选择“雨伞、钥匙、保温杯、耳机”之一，再进入查询中及对应结果；耳机预置为空结果。筛选采用“全部校园信息”及雨伞 / 图书馆 / 近7天、钥匙 / 教学区 / 今天、水杯 / 食堂 / 近7天四组明确的快捷条件，支持选择、取消、重置和应用；关键词与条件不匹配时进入该关键词的空态。铜盘校区提供未覆盖空态，不显示旗山物品。这些是已绘制的有限页面与连线，不能推导为任意关键词、独立条件的全部组合或数据查询均已实现。

v2 布局调整包括：删除首页长搜索框、快速入口与三个信息分类标签；顶部保留品牌、校区下拉按钮和独立圆形搜索按钮；校区及筛选箭头、返回、关闭与搜索均采用矢量图标。导航胶囊与独立编辑圆钮悬浮在内容上方，移除整块底栏背景并对齐底边；“我的”增加未读提示。顶部返回及发布关闭采用返回上一页，右侧原省略号入口改为透明标题平衡留白。

一级“我的”去掉顶部返回，改为标题加草稿箱、帮助记录、消息待办三个圆形图标按钮，并移除正文中重复的工具行。草稿箱是独立列表，帮助记录进入默认空的协助记录页；从“我的”进入发布后，关闭可回到“我的”。

在原初稿基线上复现 v2 的顺序：

1. `revise-layout-v2.js`：修订既有主页面布局。
2. `revise-navigation-v2.js`、`revise-search-v2.js`：生成导航回执及搜索筛选布局。免费版中部分反应写入会被拒绝，不能在这一步视为完成。
3. `repair-search-free.js`、`repair-business-free.js`：应用免费版兼容的单动作反应和静态状态页面，再做实际原型检查。
4. `polish-free-v2.js`：调整普通正文与筛选入口排版，保留已实测可自动过渡的参数；继续逐项验证实际原型。
5. `repair-mine-header.js`：在业务副本生成后统一整理一级我的顶部，建立独立草稿列表。
6. `repair-final-qa.js`：同步最终文字、帮助记录目标与关键词返回行为修复，再核对当前节点和原型界面。
7. `repair-flow-final.js`：补齐转报草稿和保存回草稿箱的入口，统一详情底部返回与编辑文案；执行后重新统计并走查新增保存路径。

上述9个 v2 修订及修复脚本均已通过本地 `node --check`；语法检查不等于 Figma 执行成功或 UI 验收。

上述顺序用于说明来源与依赖，不应在已修复的当前文件上无条件重复运行生成脚本。`figma-transfer.html` 为早期网页传输辅助文件；`build-figma.js`、模板、`screens.json` 与 SVG 保留初稿基线，v2 以补充修订和最终免费版修复脚本共同组成。
