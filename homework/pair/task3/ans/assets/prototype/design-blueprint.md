下表保留需求阶段的风险验收目标，不等同于每项都已完成实际交互测试。`screens.json` 记录当前制作范围，实际点击范围见下一节。

| 异常 | 后续逐项验收时应核对的反馈与恢复路径 |
| --- | --- |
| E01 字段错误 | 就近错误、定位首项、保留其他输入；允许未知，不强迫编造日期地点 |
| E02 读取失败 | 与无结果区分；重试 / 返回；候选失败仍可手动发布 |
| E03 无匹配 / 未覆盖 | 如实说明；放宽、订阅、预填发布或已确认服务点咨询 |
| E04 身份 / 权限不足 | 保留原操作；成功返回原事项，取消失败仍可公开浏览 |
| E05 提交结果未知 | 提交中 → 结果确认中 → 查询本次结果；确认未收到才重试 |
| E06 旧状态 / 过期 / 下架 | 读取最新允许公开状态，收起失效动作，继续查找或申诉 |
| E07 图片问题 | 标明具体图及原因；替换 / 遮挡 / 移除 / 无图继续；失败附件不冒充成功 |
| E08 交接受阻 | 待回复、争议、关闭、冲突；补证 / 改约 / 取消 / 服务点，不超时自动完成 |
| E09 退回 / 无人值班 | 原因、受理时间、处理时段、升级入口；修改 / 撤回 / 申诉 / 等待 |
| E10 联系撤回 | 联系入口收起，提供站内事项和校内中转路径 |
| E11 推送 / 回告失败 | P08 / O01 保留待办及原因；已发送不等于已处理 |
| E12 激励不可用 | 未开放、额度不足、重复、不通过分别说明；保留贡献与申诉，不虚构加分 |
