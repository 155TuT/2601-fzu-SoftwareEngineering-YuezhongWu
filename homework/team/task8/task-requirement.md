# 2026秋软工实践团队作业-第三次（Alpha 冲刺）

作业发布时间为 2026-11-10 12:00，博客提交截止时间为 **2026-11-21 23:59**。

[博客园作业原文](https://edu.cnblogs.com/campus/fzu/202601SofwareEngineering/homework/16792)

## 冲刺过程

- 回顾此前展示的项目和已完成的工作，提出项目改进方案，并展示团队协作过程。
- Alpha 冲刺至少持续 **14 天**，在冲刺总结中体现。
- 每次冲刺安排约 **10 分钟**的站立会议，控制时间，细节另行讨论。全员到场，缺席须说明原因。

## 博客与 Vlog

准备 1 篇冲刺计划、1 篇冲刺总结和 1 个 Vlog，三项共 100 分。**队长在博客园作业入口只提交冲刺总结**，随笔标题为 `团队名称-冲刺总结`。

### 冲刺计划（15 分）

1. 总结和反思此前的团队工作，给出改进思路和方案。
2. 用表格列出每位成员实际承担的工作和工作量。

### 冲刺总结（60 分）

1. 说明冲刺计划中的项目改进是否全部实现，列出项目亮点和目前的不足。
2. 附上冲刺计划链接。
3. 记录每位成员的过程体会。
4. 说明每位成员完成的工作及其占整个冲刺阶段工作量的比例。
5. 附上团队大作业的 GitHub 仓库链接。

### Vlog（25 分）

1. 标题自拟，时长 **3–5 分钟**。
2. 简要介绍冲刺计划。
3. 展示每天冲刺日志的重要内容，以及开发过程中与队友的交流。
4. 将每天拍摄的视频素材剪辑成一个完整视频。

## GitHub 仓库

1. 将本次作业的 PPT 放入第一次团队作业要求建立的大作业 GitHub 仓库。
2. 每有一项较大进展，发布对应的 GitHub Release，版本号遵守行业命名规范。

## 答辩 PPT

1. 项目成员分工和预期计划。
2. 项目实际进度曲线和燃尽图。
3. 遇到的问题及解决办法。
4. 项目实际架构，包括前后端开发框架、所用技术和部署流程等。
5. 项目测试工作的安排、测试工具的选择与使用，以及对测试工作的评述。
6. 成员的过程体会。

## 现场答辩

1. PPT 演讲。
2. 展示作品。演示同学携带电脑，提前调试并确认项目可以运行。如需将手机或其他设备投屏到电脑，提前准备并调试。
3. 播放 Vlog。

每组演示限 **15 分钟**，超时扣分。PPT 演讲和作品演示合计 **10 分钟**，Vlog 展示 **5 分钟**。

## 评分标准

现场部分满分 100 分。

| 现场评分项 | 分值 |
| --- | ---: |

| 演讲 | 10 |
