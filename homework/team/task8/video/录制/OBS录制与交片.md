# 用 Marp 和 OBS 录成片

电脑负责全屏放映，手机打开[逐页旁白](../放映/逐页旁白.md)。一段录屏从头讲到尾，素材在讲到对应页时切进去。用到的操作是截图、切画面和裁首尾。

## 1. 收到图，换进 Marp

1. 打开 VS Code，编辑[放映稿](../放映/下一位同学拿到什么.md)。两张会议 PNG 放进 `素材/入片/`，文件名按[逐日素材单](../素材/逐日素材单.md)。
2. 第 2、3 页各有一行以 `> ![` 开头的图片，当前放的是已留存的交接稿。把这一行换成同页备注里给的图片行，再把下一行图注换成实际拍摄日、全名和动作。例如第 2 页可写成下面这样。

   ```markdown
   > ![两位成员对晚餐样例的预期](../素材/入片/02-会议-晚餐样例.png)
   >
   > 11 月 20 日 · 林金晶共享样例，林叶鑫标出预期
   ```

3. 第 4–7 页想放新材料时，照这个写法替换该页右栏两段引用。各页备注都列了文件名。定稿成员感想时，改放映页粗体全名后面那一句，并把同一句带到该页备注和手机用的旁白稿。
4. 在 VS Code 按 `Ctrl+Shift+V` 预览，检查 8 页和两张新图。点编辑器 Marp 图标，选 **Export Slide Deck… → HTML**，把临时放映页存到与 Markdown 同一个 `放映/` 目录。用 Chrome 打开导出的 HTML，按 `F11` 全屏，把鼠标移到画面上方，等底部翻页条收起，再用方向键翻页。改过 Markdown 或替换了图片就重新导出、刷新，试翻一次。[Marp for VS Code 的导出说明](https://github.com/marp-team/marp-vscode#export-slide-deck-to-html-pdf-pptx-and-image-)

## 2. 今晚只录这 6 秒

按[主持单](../会议/十分钟主持单.md)取得同意后，王智壹在 OBS 建“会议”场景，加一个“窗口采集”，选实际能看到共享材料的窗口。林金晶和马晨曦共享时各截一张。马晨曦指向提示语、陈柏睿接话时打开录制，留约 6 秒后停止。把原片存进 `素材/会议原片/` 并登记。最终用这段画面时由王智壹配音。

OBS 的“设置 → 视频”可选 1920 × 1080、30 帧，输出录制选 MKV。需要 MP4 时，在“文件 → 录像转封装”选刚录的 MKV。先试录 10 秒，回放看文字和音量。[OBS 快速入门](https://obsproject.com/kb/quick-start-guide) · [录制与转封装](https://obsproject.com/kb/standard-recording-output-guide)

## 3. 把每天的短片接进放映

1. 按素材单，从每个实际工作日的原片里裁出 4–6 秒。保留原文件，短片按日期和动作另存。例如 20 日的小片叫 `11-20-共享保存提示.mp4`。19 日若只收到了当日截图，就用这张图，旁白照实说拍摄日和材料类型。
2. 在 OBS 建“放映”场景，加一个“显示器采集”，选放映用的屏幕。再给有素材的每个日期建一个场景，加“媒体源 → 本地文件”选短片，勾选“当源变为活动状态时重新开始播放”。若这一天收的是截图，用“图像”来源。选中来源按 `Ctrl+F`，让它适配画布。
3. 在“设置 → 快捷键”给“切换到场景”分配组合键，如 `Ctrl+Alt+1` 切放映、`Ctrl+Alt+2` 切 19 日、`Ctrl+Alt+3` 切 20 日。在 Chrome 全屏时各按一次试切。素材场景保留麦克风声音，把短片自身的音量关掉，旁白就能连续录下去。
4. 按[逐页素材安排](../素材/逐日素材单.md)切画面。第 2 页讲“十一月十九日”时切到当日原片或截图，4–6 秒后切回。第 3 页讲保存提示时切 20 日的 6 秒短片。后续日期用相应的交接页，切片时在旁白里先念实际日期。照片和短片都算进该页的时长。

## 4. 一次录完

- 关桌面通知。Chrome 停在第 1 页，OBS 选“放映”，试录开场一句，回放确认只录到幻灯片，自己说话能听清。
- 正式录制时按手机上的全名念，翻页时稍停，留时间给听众看交接动作。到第 7 页用已经复核的正式包和两份结果收尾，第 8 页读王智壹的感想，停两秒再结束。
- 转封装成 MP4，裁去首尾操作，另存为 `成片/下一位同学拿到什么.mp4`。从头播放一次。总时长 **3–5 分钟**，11 位成员的署名分享都在，日期和原片对得上，两张会议图能看出谁在把材料交给谁。
