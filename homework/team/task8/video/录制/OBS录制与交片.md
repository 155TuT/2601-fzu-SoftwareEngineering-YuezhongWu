# 一台电脑录完放映和旁白

## 填图和念白

1. 打开[逐日素材单](../素材/逐日素材单.md)，用 `Win + Shift + S` 截自己已有的 Issue、PR 和项目聊天。保存为 PNG，逐张覆盖 `素材/入片/` 里的同名底图。优先截一处能读清的交接，聊天保留原消息日期。
2. 在 VS Code 打开 [Marp 放映稿](../放映/下一位同学拿到什么.md)，搜索 `【待填｜`。把含括号的整段换成一句能直接念的话，每处约 15–25 字。全名保留。每页的固定旁白在备注里，也可查看[逐页旁白](../放映/逐页旁白.md)。
3. 槽位里的事实还在推进时，填入当前能核到的那一步。例如任务单只有接手要求，就讲“这一步约定由谁接、拿什么来验”。提到试用、真机或正式发布时，用图里的实际版本和结果。

## 用 Marp 在本机放映

在 VS Code 按 `Ctrl+Shift+V` 预览，确认 8 页的截图和文字都放好了。点编辑器的 Marp 图标，选择 **Export Slide Deck… → HTML**，把 HTML 存在 Markdown 同一个 `放映/` 目录。用 Chrome 打开它，图片将从旁边的素材目录读取。更换图片或改词后，重新导出并刷新。[Marp for VS Code](https://github.com/marp-team/marp-vscode)

在放映页按 `P` 打开演讲者视图。普通放映窗口留给 OBS，自己看演讲者窗口里的当前页和备注。用方向键翻页，两个窗口同步。一块屏幕即可读稿和录制。

## 用 OBS 一次录完

1. 新建一个场景，在“来源”里加“窗口采集”，选 **普通放映窗口**。预览中应只看见观众要看的幻灯片。可让普通窗口先按 `F11` 全屏，再切回演讲者窗口。OBS 只开自己的麦克风，桌面音频静音。
2. 视频可用 1920 × 1080、30 帧，录制格式选 MKV。先试录十秒，念一句、翻一页，回放看截图是否能读清、画面是否跟着翻页、自己的声音是否听得清。
3. 回到第一页开始正式录制。一页一张图，先念固定旁白，再读左侧已经填好的短句。第 8 页念完停两秒，结束录制。
4. 用 OBS 的“文件 → 录像转封装”转成 MP4，裁掉首尾切窗口的部分，存到 `成片/下一位同学拿到什么.mp4`。从头看一遍，确认全片 **3–5 分钟**、工作日期清楚、画面没有“待配图”或“待填”字样。[OBS 录制与转封装](https://obsproject.com/kb/standard-recording-output-guide)
