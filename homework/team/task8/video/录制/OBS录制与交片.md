# 一台电脑录完放映和旁白

## 填图和念白

1. 单页 02 显示 Issue #1 的派单清单。单页 13 显示 GitKraken 提交图，录制时从底部的契约测试讲到顶部 PR #20 合入主线。[GitKraken 截图](../素材/入片/11-21-GitKraken-契约测试.png)
2. 在 VS Code 打开 [Marp 放映稿](../放映/下一位同学拿到什么.md)，搜索 `【待填｜` 核对交接记录。录制时，按演讲者备注或[逐页旁白](../放映/逐页旁白.md)的引用框念。画面上的姓名标明谁交付、谁接手，整段由王智壹一人讲。
3. 录制前若拿到新的真机或交包记录，把对应那句更新成实际版本、测过的操作和看到的结果。

## 用 Marp 在本机放映

在 VS Code 按 `Ctrl+Shift+V` 预览，确认 17 张放映单页的截图和文字都放好了。导出录制版时，可以把稿首样式 `section li em` 里的 `display: block` 临时改为 `display: none`，收起小字提示。点编辑器的 Marp 图标，选择 **Export Slide Deck… → HTML**，把 HTML 存在 Markdown 同一个 `放映/` 目录。导出后把样式改回 `block`，继续按原提示查找。用 Chrome 打开 HTML，图片会从素材目录读取。[Marp for VS Code](https://github.com/marp-team/marp-vscode)

在放映页按 `P` 打开演讲者视图。普通放映窗口留给 OBS，自己看演讲者窗口里的当前页和备注。用方向键翻页，两个窗口同步。一块屏幕即可读稿和录制。

## 用 OBS 一次录完

1. 新建一个场景，在“来源”里加“窗口采集”，选 **普通放映窗口**。预览中应只看见观众要看的幻灯片。可让普通窗口先按 `F11` 全屏，再切回演讲者窗口。OBS 只开自己的麦克风，桌面音频静音。
2. 视频可用 1920 × 1080、30 帧，录制格式选 MKV。先试录十秒，念一句、翻一页，回放看截图是否能读清、画面是否跟着翻页、自己的声音是否听得清。
3. 回到单页 01 开始录制，按照[逐页旁白](../放映/逐页旁白.md)在每个翻页标记处按一次右方向键。单页 17 念完停两秒，结束录制。
4. 用 OBS 的“文件 → 录像转封装”转成 MP4，裁掉首尾切窗口的部分，存到 `成片/下一位同学拿到什么.mp4`。从头看一遍，确认全片 **3–5 分钟**、工作日期清楚、画面没有“待配图”或“待填”字样。[OBS 录制与转封装](https://obsproject.com/kb/standard-recording-output-guide)
