# 《下一位同学拿到什么？》冲刺 Vlog

这是一份按叠石 Android `v0.1.0` 发布、复核后回看的成片稿。王智壹用 8 页 Marp 讲约 **3 分 50 秒**。11 位同学每人留一句交接后的体会，署全名，由王智壹代读。影片跟着晚餐样例、保存回执和候选安装包在人与人之间走一遍。产品功能和架构留给汇报时展开。

| 什么时候 | 直接用哪份文件 | 需要做什么 |
| --- | --- | --- |
| 发通知 | [成员口播卡](会议/成员口播卡.md) | 复制群通知。11 位成员各有准备动作和两句底稿，最后一句由本人按实际经历改定。 |
| 今晚 22:00 | [十分钟主持单](会议/十分钟主持单.md) | 王智壹点全名。林金晶和马晨曦各共享一个窗口。留两张协作截图，其中一次共享再录约 6 秒。 |
| 每次交接后 | [逐日素材单](素材/逐日素材单.md) | 收当日原片和日志、接手人与一句心得。保留已有的 11 月 19 日里程碑图、20 日两份交接稿原图。 |
| 全流程走完 | [Marp 放映稿](放映/下一位同学拿到什么.md) · [逐页旁白](放映/逐页旁白.md) | 把两张会议图放到第 2、3 页，第 4–7 页可换一张最能看出修改经过的材料。定稿 11 句署名原话，对好候选验收、发布和复核记录。 |
| 录成视频 | [OBS 录制与交片](录制/OBS录制与交片.md) | 在本机全屏放映，按实际工作日穿插几秒原片，王智壹边翻页边讲。最后裁首尾，导出 MP4。 |
