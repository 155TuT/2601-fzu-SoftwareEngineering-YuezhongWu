# 2026秋软件工程现场编程作业

作业提交期限（Deadline）：2026-11-07 23:00

作业要求：[2026秋软件工程现场编程作业](https://edu.cnblogs.com/campus/fzu/202601SofwareEngineering/homework/16782)

## 作业描述

开发一个个人记账本，供用户简单记录、查看和统计日常收入与支出。

### 功能需求

1. **基础记账：** 记录每笔支出或收入，包括日期、金额、类别（如饮食、交通、工资等）和备注。使用本地文件保存数据，例如 JSON 或 CSV。
2. **查看数据：** 查看最近的几笔记录。
3. **收支统计：** 根据日期、类别、金额等查看总支出和总收入情况。
4. **用户友好型：** 程序应具备易于使用和操作的用户界面。
5. **附加功能（可选）：** 简单的图表展示。

## 实现要求

1. 团队使用 GitHub 协作，**每个人都需要有自己负责部分的提交记录**。请新建一个仓库，不要与团队作业或其他作业共用。
2. 软件成品可以使用 Web 界面、APP 等方式呈现，但必须在 17:00 后能够演示。
3. 软件必须由多个模块组成，例如记录、查看、统计、界面等。组内每位同学都要独立完成至少一个模块的编写；如果发现伪造提交记录或代写代码行为，本次作业按 0 分处理。
4. 17:00 在 GitHub 上发布当前软件的 Release 版本。

## 现场演示

现场编程结束后（17:00 后），各个团队需要向助教演示软件。演示方式于当天 16:45 公布。
